# DevOps Planning

This directory contains local planning artifacts that mirror an Azure DevOps backlog structure.

## Structure

- `Epics` contains large work packages
- `Features` contains slices of epic scope
- `BacklogItems` contains actionable backlog entries
- `Tasks` contains implementation-level work items
- `Gates` contains mandatory architecture, quality, integration, and release-readiness checks

## Active plan

- [Shared CodeStudio Components](Features/F-Shared-CodeStudio-Components.md) plans reusable configuration, configuration UI, project explorer, property editor, and diagnostics navigation components.

## Completion policy

Each task must record its planned and executed tests, relevant build results, an English SVN commit revision and message, and the updated status of the current and next task, backlog item, and feature before it can be marked Done.
