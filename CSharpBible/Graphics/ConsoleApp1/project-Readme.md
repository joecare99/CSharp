# ConsoleApp1: Color Vision Visualization Tool

## 🗺️ Role and Purpose
This application generates a stereo view of a 3D cubic lattice graph (composed of R, G, B nodes). The visualization demonstrates the concept of proximity in color space by connecting nodes whose colors are adjacent in the R, G, and B axes (Manhattan distance of 1). The application projects the 3D positions onto a 2D plane, simulating stereo vision using slight eye offsets.

## 🏗️ Architecture & Components
*   **Core Logic:** Implemented in `Program.cs`. Handles node generation (`CreateNodes`) and neighbor linking (`BuildNeighbors`).
*   **Math Utilities:** `MathHelpers.cs` centralizes all geometric transformations (Matrix rotation, Vector dot products, 3D to 2D projection) and color conversions (RGB to HSL).
*   **Dependencies:** Relies on `System.Drawing.Common` for image manipulation and `CommunityToolkit.Mvvm` (though not strictly used here, it suggests the overall solution context).

## 🌟 Best Practices & Notes
*   **Stereo View:** The use of `baseline` (eye separation) and small offsets in the camera position is critical for the perceived depth effect.
*   **Color Space:** The R, G, B cubic structure inherently maps well to the Manhattan distance metric, making it a good visual representation of spatial adjacency.
*   **Performance:** Projection calculations should ideally be optimized using SIMD instructions if scaling to thousands of nodes.
