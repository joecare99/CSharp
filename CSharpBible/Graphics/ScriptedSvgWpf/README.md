# Scripted SVG WPF

Scripted SVG is a small standalone WPF editor for a typed, C#-inspired drawing
language. It uses only native .NET/WPF APIs for parsing, interpretation,
preview, and SVG generation. The editor itself uses CommunityToolkit.Mvvm and
Microsoft.Extensions.DependencyInjection.

The bundled example demonstrates a white canvas and a parity-selected
checkerboard generated by nested `for` loops. Each square is positioned on a
fixed grid, scales linearly toward zero at the canvas center, and rotates
counterclockwise around its own center.

Example commands:

```text
canvas(640, 480, "white");
rect(10, 10, 80, 40, "black", 0.8, 15);
circle(140, 30, 20, "tomato");
line(0, 0, 200, 100, "navy", 2);
text(10, 120, "Hello", "black", 18);
polygon([Point(10, 140), Point(80, 140), Point(45, 200)], "seagreen");
path("M 100,140 L 180,200", "purple", 2);
```

The built-in `Math` functions include `abs`, `sqrt`, `sin`, `cos`, `tan`,
`atan`, `atan2`, `floor`, `ceil`, `round`, `min`, `max`, and `pow`; `Math.PI`
is also available. Syntax errors show the line, column, source line, and a
caret marker. Runtime errors are reported separately from syntax errors while
the last valid preview remains available.

Execution is bounded by configurable step, loop, and drawing-command limits,
so a malformed or accidental infinite script cannot consume the editor.
